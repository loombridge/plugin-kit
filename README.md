# plugin-kit

The plug-in kit is a set of Rust crates for building audio plug-ins: real-time safety, parameters, commands and the agent interface, DSP building blocks, voices, modulation, effects, wavetables, sequencing, presets, UI widgets, the plug-in formats (CLAP natively, with VST3, Audio Unit, a standalone app and a native Beatlayer device made from it) and a headless test harness. Every crate carries the prefix `lspk-`. It is in early development and has no stable API yet. Licensed under either of [Apache-2.0](LICENSE-APACHE) or [MIT](LICENSE-MIT), at your option.
